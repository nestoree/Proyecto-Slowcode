Proyecto Slowcode - Tamagotchi Virtual

🖥️

Compatibilidad de Pantalla

Esta aplicación está optimizada exclusivamente para PC. La interfaz, los controles del Arcade y la experiencia visual no están diseñados para dispositivos móviles o tablets.

¿Qué es Slowcode?

Este proyecto es un tributo a los juguetes clásicos de los 90, adaptado a la web moderna con un enfoque educativo.

Tecnologías utilizadas

HTML5 CSS3 (Flexbox/Glass) JavaScript (Vanilla) Google Fonts

Funcionalidades clave

  • Sistema de estadísticas en tiempo real.
  • Tienda de consumibles con validación de puntos.
  • Menú lateral interactivo con Overlay.
  • Navegación entre mini-juegos y configuración.
